# Code of Conduct

We want Kubeglass to be a welcoming project for everyone.

Be respectful and constructive. Assume good intent, focus on the work, and accept feedback gracefully. Harassment, discrimination, personal attacks and publishing other people's private information are not acceptable in any project space.

This project follows the spirit of the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

To report unacceptable behaviour, contact the maintainers privately (see [SECURITY.md](SECURITY.md) for the private channel). Reports are handled confidentially.
